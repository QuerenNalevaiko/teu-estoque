# Requisitos do projeto — Teu Estoque

## 1. Requisitos funcionais

RF01 — O site deve possuir uma área inicial apresentando o nome "Teu Estoque".

RF02 — O site deve possuir menu de navegação para acessar as principais seções da página.

RF03 — O menu deve levar o usuário até as seções correspondentes utilizando rolagem dentro da mesma página.

RF04 — O site deve apresentar os principais recursos oferecidos pelo Teu Estoque.

RF05 — O site deve apresentar uma representação visual de um painel de gerenciamento de estoque.

RF06 — O site deve apresentar produtos fictícios com informações de quantidade em estoque.

RF07 — O site deve apresentar visualmente pelo menos um produto identificado como estoque baixo.

RF08 — O site deve apresentar indicadores relacionados ao estoque, como quantidade de produtos, estoque baixo e movimentações.

RF09 — O site deve possuir pelo menos um botão de chamada para ação.

RF10 — Os elementos devem possuir efeitos visuais ativados durante a rolagem da página.

RF11 — O site deve possuir uma seção final de chamada para utilização do Teu Estoque.

RF12 — O site deve possuir rodapé com identificação do projeto.

## 2. Requisitos não funcionais

RNF01 — O site deve ser desenvolvido utilizando HTML5.

RNF02 — A aparência do site deve ser construída utilizando CSS3.

RNF03 — Os comportamentos devem utilizar JavaScript.

RNF04 — O projeto deve utilizar pelo menos uma biblioteca JavaScript de efeito visual.

RNF05 — O site deve funcionar localmente ao abrir o arquivo index.html.

RNF06 — O site deve ser apresentado em uma única página.

RNF07 — A navegação entre as áreas deve ocorrer sem carregar outras páginas.

RNF08 — O site deve possuir layout responsivo.

RNF09 — O conteúdo deve continuar legível em telas de aproximadamente 360 pixels de largura.

RNF10 — O site não deve depender de servidor ou banco de dados para funcionar.

RNF11 — A identidade visual deve utilizar uma paleta consistente.

RNF12 — O código HTML, CSS e JavaScript deve permanecer separado nos arquivos index.html, estilo.css e script.js.

RNF13 — O site não deve apresentar erros JavaScript no console do navegador.

RNF14 — O projeto deve utilizar a biblioteca AOS para animações de entrada durante a rolagem.
