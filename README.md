# Teu Estoque

Landing page acadêmica desenvolvida para apresentar o **Teu Estoque**, uma solução fictícia de gerenciamento de estoque voltada a pequenos negócios.

O projeto apresenta uma interface demonstrativa para acompanhamento de produtos, movimentações e níveis de estoque de maneira simples e organizada.

> **Observação:** este é um projeto acadêmico. Os produtos, indicadores, quantidades e depoimentos apresentados no site são dados fictícios utilizados exclusivamente para demonstração visual.

---

## Funcionalidades

- Página única com navegação entre seções;
- apresentação dos principais recursos do Teu Estoque;
- painel demonstrativo de controle de estoque;
- indicadores de produtos e níveis de estoque;
- representação de produtos com estoque baixo;
- seção explicando o funcionamento da solução;
- apresentação de vantagens;
- depoimentos fictícios para demonstração;
- FAQ interativo;
- menu responsivo para dispositivos móveis;
- rolagem suave entre as seções;
- animações durante a rolagem utilizando AOS;
- layout adaptado para desktop, tablet e celular.

---

## Tecnologias utilizadas

### HTML5

Responsável pela estrutura e organização semântica do conteúdo da página.

### CSS3

Responsável pela identidade visual, layouts com Flexbox e Grid, responsividade, espaçamentos, tipografia, botões, cards e demais componentes visuais.

### JavaScript

Utilizado para os comportamentos da página, incluindo menu mobile, navegação interna, rolagem suave e integração das animações.

### AOS 2.3.1

Biblioteca **Animate On Scroll**, utilizada para adicionar animações de entrada aos elementos durante a rolagem da página.

A biblioteca é carregada através da CDN do UNPKG.
