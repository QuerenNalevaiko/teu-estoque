# INSUMOS — TEU ESTOQUE

## 1. Tema do projeto

O projeto "Teu Estoque" consiste em uma landing page para divulgação de uma solução fictícia de gerenciamento de estoque destinada principalmente a pequenos negócios.

A proposta é apresentar de forma simples recursos como acompanhamento de produtos, quantidades disponíveis, movimentações e alertas de estoque baixo.

## 2. Referências visuais

Foram utilizadas duas páginas como referência visual para planejamento da estrutura e da identidade do projeto.

### Referência 1 — GestãoClick

Arquivo utilizado:
imagens/pagina-gestao-click.png

Origem:
Página pública do GestãoClick.

URL:
https://gestaoclick.com.br/controle-de-estoque/

Elementos utilizados como referência:

imagens/pagina-kyte.png

## 3. Decisões tomadas a partir das referências

O Teu Estoque utilizará uma combinação das ideias observadas nas duas referências.

Da página GestãoClick será aproveitada principalmente a ideia de estrutura de landing page extensa e demonstração de um software de gestão.

Da página Kyte será aproveitada principalmente a organização visual, o uso de espaços em branco, cards e apresentação simplificada das funcionalidades.

O projeto terá identidade própria e não reproduzirá integralmente nenhuma das páginas.

## 6. Restrições estabelecidas antes do desenvolvimento

- O projeto deve possuir somente uma página.
- Não utilizar React.
- Não utilizar Next.js.
- Não utilizar Vue.
- Não utilizar Bootstrap.
- Não depender de Node.js.
- Não utilizar banco de dados.
- Não exigir servidor para abrir.
- Não copiar textos das referências.
- Não copiar imagens pertencentes aos sites de referência para o site final.
- Não copiar logotipos das referências.
- Não reproduzir integralmente nenhuma identidade visual.
- Não colocar HTML, CSS e JavaScript no mesmo arquivo.
- Não utilizar animações excessivas.
- Não prejudicar a leitura em telas pequenas.
- O site deve funcionar ao abrir index.html diretamente no navegador.
